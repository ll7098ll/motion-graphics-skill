# Adaptive Motion Graphics & Prompt-Motion Skill

This skill guides the **autonomous concept structuring, prompt-motion.com level prompt engineering, context-aware art direction, and broadcast-quality React/Remotion implementation** of modern motion graphics.

> **Core Philosophy**:
> "Form follows context, polish commands attention."  
> When a user gives any topic, do not output generic slides or flat shapes. Deconstruct the topic's essence, build a beat-synced storyboard, formulate a `prompt-motion.com` grade master prompt, and craft high-fidelity React compositions with tangible 3D depth, fluid springs, and kinetic typography.

## 2. Topic Diagnosis & Concept Structuring (Phase 1)

When the user provides a topic (e.g., *"AI Developer Copilot"*, *"FinTech Card"*, *"Cyber Security Shield"*, *"Artisan Coffee Roastery"*, *"Designer Showreel"*), immediately synthesize:

1. **Domain Essence & Visual Metaphor**:
   - Don't settle for abstract boxes. Map authentic domain objects (see `references/concept-to-composition.md`):
     - *DevTools/AI*: Terminal cursor, AST node graphs, split diffs, latency rolling meters.
     - *FinTech*: Heavy obsidian metal card, 3D tilt glint, encrypted chip, ledger stream.
     - *Security*: Hexagonal shield lattice, radar sweep, green/red status chip flip.
     - *Mobility/Aviation*: Great Circle flight arcs, altimeter telemetry, horizon lighting.
2. **Beat-Synced 4-Act Storyboard (120 BPM, 1 beat = 0.5s = 30 frames at 60fps)**:
   - **Act 1: The 0.8s Thumb-Stopper Hook (0%–20%)**: Dramatic entry with initial velocity.
   - **Act 2: The Tangible Engine / Substance (20%–60%)**: 2–3 micro-events (data rolls, chart draws, spring clicks).
   - **Act 3: Spatial Elevation / Climax (60%–80%)**: 3D camera pan/tilt, macro perspective, radiant burst.
   - **Act 4: Iconic Payoff & Poster Hold (80%–100%)**: Signature emblem locks, slogan reveals, 1.5s freeze-frame hold.
3. **Object Handoff**: Identify which hero element continuously morphs between scenes without cuts.

## 3. Mandatory Pre-Flight Asset Inquiry (Phase 2)

Unless the user has already provided image assets or logos in their prompt, **actively ask about their existing assets**:

> **Asset Inquiry Standard**:
> "혹시 영상에 활용할 **브랜드 로고(SVG/PNG), 제품 스크린샷, 실사 사진, 공식 색상(HEX), 슬로건** 등의 에셋이 있으신가요?
> 1. **보유 에셋이 있으신 경우**: 경로를 알려주시거나 프로젝트 내 `public/` 폴더에 넣어주시면 영상에 정밀하게 맵핑해 드립니다.
> 2. **보유 에셋이 없으시거나 자율 제작을 원하시는 경우('알아서 해줘')**: 제가 브랜드의 공식 CI 벡터를 자체 복원하고, 시네마틱 비주얼과 맞춤형 UI 컴포넌트를 직접 디자인하여 완성해 드립니다."

- **Track A (User Assets)**: `staticFile('...')`, Ken Burns micro-pan, 3D perspective display (`references/asset-orchestration.md`).
- **Track B (Zero Assets / Autonomous)**: Autonomously reconstruct SVG CI emblems, generate vector badges, and design domain UI (`references/brand-identity-and-ci.md`).
- **Track C (Hybrid)**: Extract color tokens from a provided URL/logo; autonomously build the UI world around it.

## 4. Prompt-Motion.com Master Prompt Generation (Phase 3)

Reverse-engineered from the top 200+ viral motion pieces on **https://prompt-motion.com/**, every master prompt MUST include these **6 Pillars**:

```markdown
[ROLE & PERSONA]
Act as a world-class motion designer and creative technologist (Apple Keynote, Stripe Press, Pentagram standard). Build a broadcast-grade [DURATION]-second 60fps Remotion composition for "[TOPIC]".

[CREATIVE DIRECTION & AESTHETIC]
- Style: [Select from 7 Design Languages: e.g., Luxury Dark Titanium / Swiss Brutalism]
- Palette: [Explicit Hex Tokens: Canvas, Surface, Hairline, Accent, Text]
- Atmosphere: Radial gradient spotlight, 48px dot matrix, floating particles, no flat voids.
- Typography: High-contrast pairing (Headline 800 weight sans + Monospace telemetry tags).

[BEAT-SYNCED TIMELINE BREAKDOWN (120 BPM, 60fps)]
- 0.0s – 2.5s: "The Genesis Hook" (High-velocity emergence, masked typography reveal)
- 2.5s – 7.0s: "The Tangible Engine" (3D tilted card, rolling counters, animated SVG spline)
- 7.0s – 11.0s: "Spatial Elevation" (3D camera sweep, cluster network convergence)
- 11.0s – 15.0s: "Signature Climax & Payoff" (Emblem assembly, border beam, slogan lockup, poster hold)

[MOTION PHYSICS & REMOTION DIRECTIVES]
- Physical spring config: damping 14~18, stiffness 120~180, mass 0.8~1.0.
- Stagger child reveals by 3~4 frames.
- 3D perspective container (1200px, subtle rotateX/rotateY).
- Continuous hero object handoff across scenes.

[STRICT BANNED CLICHÉS]
- No generic opacity crossfades or PowerPoint slides.
- No static unmoving elements or empty uncluttered voids.
- No jumping raw integers (always interpolate continuous counters).

[TECHNICAL STACK]
Complete, self-contained, and runnable React Remotion TSX code.
```

## 5. Studio-Grade Visual Polish & Polish Recipes (Phase 4)

To match the visual benchmark of `prompt-motion.com`, implement these proven recipes in Remotion:

1. **3D Perspective Camera Rig**: Wrap compositions in `perspective: 1200`, `rotateX(4deg)`, `rotateY(-6deg)` with time-based micro-drifts (`references/studio-polish-recipes.md`).
2. **Border-Beam Shimmer**: Conic-gradient sweeping light beam around hairline card borders (`references/studio-polish-recipes.md`).
3. **Masked Kinetic Typography**: Per-word upward slide from an `overflow: hidden` container driven by staggered springs.
4. **Jitter-Free Rolling Counters**: Smooth `interpolate()` mapped with `fontVariantNumeric: tabular-nums` and `.toFixed(1)`.
5. **Living Atmosphere**: 48px subtle dot grid combined with pulsing radial gradient glow spotlights.
6. **Animated SVG Spline Charts**: Dynamic curves drawing via `strokeDasharray` and `strokeDashoffset`.

| **D. Multi-Chapter Explainer** | `30s – 60s` (60–120 beats) | **Chaptered Journey**: Pain Point → Architectural Shift → Live Deep-Dive UI → Ecosystem & Integrations → Anthem. | SaaS explainers, institutional overviews |
| **E. Continuous Shape Morph** | Any duration | **Unbroken Identity**: Exactly one primary container morphs dimension, radius, and contents without cuts. | Tactile UI showcases, infinite web loops |

## 8. Remotion Project Architecture & Execution CLI

```
my-motion-project/
├── package.json             # remotion, @remotion/cli, react, react-dom
├── remotion.config.ts       # System GPU D3D11/OpenGL acceleration
├── tsconfig.json            # ES2022, NodeNext, jsx: react-jsx
└── src/
    ├── index.ts             # registerRoot(Root) entry point
    ├── Root.tsx             # <Composition> registry (durationInFrames: 900, fps: 60)
    ├── Main.tsx             # Master timeline with layered sequences
    ├── components/          # 3D Rigs, BorderBeam, KineticTitle, Counters, Charts
    └── constants/           # Palette tokens, 120 BPM timing helpers
```

### Rendering Commands:
```bash
# 1. Interactive Studio preview (scrubbable timeline & real-time HMR)
npx remotion preview src/index.ts

# 2. Render 60fps Master MP4
npx remotion render src/index.ts Main out.mp4

# 3. Capture high-res keyframe still
npx remotion still src/index.ts Main still_frame.png --frame=180
```
